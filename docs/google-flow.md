# Google Flow (manual)

Flow is used by hand in its web UI (https://labs.google/flow). The app never calls Google; a Flow
subscription does not include Gemini API access.

The detailed step-by-step guide is [google-flow-production-guide.md](google-flow-production-guide.md).
In the dashboard:

1. Prompt Studio shows, per clip: model, mode, aspect ratio, the **upload order** of ingredients
   (only this character's references + product photo, with thumbnails), the prompt (copy/download),
   avoid list, expected dialogue and notes; plus an optional start-frame image prompt.
2. **Download render sheet** gives the same as `tools/render_sheet.py` (it is generated by it).
3. "Mark ready for manual render" runs the readiness check (assets exist, rights recorded, character
   active, clip lengths within the model limit) and moves the job to AWAITING_RENDER.
4. Render each clip in Flow, download, and upload it on **Render & QC** with the credits used.

`config/google-flow.json` holds what **your** account offers. Its values are unverified starter
values (`verified: false`): open Flow, check models, modes, clip length, ingredient limit, aspect
ratios and whether speech works, edit the file, set `verified: true` and `verified_by_user_on`.
The Settings page shows the current values and whether they are verified.
